# 二级分类模式补丁

此补丁针对当前项目中的 SARdetect 版本。将补丁归档内的 `D.codes/` 文件按相同相对路径覆盖到比赛镜像里的 SARdetect 根目录；先对镜像原文件做备份，并核对版本。补丁不包含模型权重、类别树或比赛数据。

原 `mixed` 模式仍为默认模式，继续使用三级检索库和按期望收益逐目标选择输出层级。新增 `classifier.mode="level2"` 只允许最高二级的训练标签，分类器使用二级目标建检索库，候选清单固定输出二级；验证真值保持原始声明深度。`evaluation.output_depth=2` 可以把已有模型的输出强制为二级，用于对照验证。

完整的预处理和训练入口说明见项目根目录 `PREPROCESS_USAGE.md`。当前工作区缺少 `B.models` 权重及 NPU 环境，补丁只通过了 CPU 单元测试、合成数据适配器测试和语法检查，未完成完整训练。
