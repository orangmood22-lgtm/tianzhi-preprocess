# 分类标签与计分规则

版本：分类积分 proxy-v3.2；标签格式 repeat-parent-v1。更新日期：2026-09-23。

本文采用用户最新确认的规则，包括“预测与真值深度不同、一级正确但二级分支错误，记0.2分”。标签的文字表示修正不会改变既有类别ID、类别树或模型权重。

## 1. 标签命名与深度

所有标签均写成三个字段，用半角连字符 `-` 分隔。尚未细分的字段重复最近一个有效类别名。

| 标签示例 | 实际深度 | 含义 |
|---|---:|---|
| `A-A-A` | 一级 | 只声明一级类别A，后两个A均为占位 |
| `A-A1-A1` | 二级 | 声明一级A、二级A1，最后一个A1为占位 |
| `A-A1-A11` | 三级 | 声明一级A、二级A1、三级A11 |

判定顺序：三个字段完全相同，判为一级；第一字段与第二字段不同、后两个字段相同，判为二级；前两字段不同、后两字段也不同，判为三级。`A-A-A11`、缺字段、空字段等形式非法。不能因为有三个字段就判为三级，也不能通过名字长度、数字位数或字符串前缀推断父子关系。实际类别路径须与标签树一致。

A、A1、A11是示例类别名。项目输出采用实际名称，例如 `Car-Car-Car`、`Car-Medium_Car-Medium_Car`、`Car-Medium_Car-Buick_Excelle_GT`。类别名称内部原有的连字符编码为 `%2D`，百分号编码为 `%25`，从而避免与字段分隔符混淆；解码后仍是原类别名。

预测JSON新增 `label` 字段存储上述格式，`label_depth` 表示真实输出深度。原有数值类别ID和内部未声明层级的 `-1` 占位继续保留，不能将各层数值ID是否相等用于判断深度。冻结数据中的 `l1/l2/l3` 与 `mixed_label_depth` 不因这次显示格式修正而重新生成。

## 2. 单目标分类积分

先确定预测、真值的有效深度，再比较有效祖先类别。重复占位字段不参加更深层的类别比较。

### 2.1 一级类别错误

只要一级类别不同，所有深度组合均记 **0分**。

例如，预测 `B-B1-B11`、真值 `A-A1-A11`，得0分。

### 2.2 同一正确分支上的深度差异

下表的前提是双方共同声明的有效类别均一致。例如真值只到一级时，不判定预测二级或三级是否正确。

| 预测标签深度 | 真值一级 `A-A-A` | 真值二级 `A-A1-A1` | 真值三级 `A-A1-A11` |
|---|---:|---:|---:|
| 一级 `A-A-A` | 1.0 | 0.6 | 0.4 |
| 二级 `A-A1-A1` | 0.8 | 1.0 | 0.8 |
| 三级 `A-A1-A11` | 0.6 | 0.8 | 1.0 |

“识别正确，无论标签粒度记1分”对应同深度且该深度的类别正确；跨深度按上表折扣计算。

### 2.3 一级正确，二级类别错误

双方都至少声明到二级，且一级一致、二级不同，统一记 **0.2分**，无论深度是否相同。

| 预测 | 真值 | 积分 |
|---|---|---:|
| `A-A2-A2` | `A-A1-A1` | 0.2 |
| `A-A2-A21` | `A-A1-A11` | 0.2 |
| `A-A2-A2` | `A-A1-A11` | 0.2 |
| `A-A2-A21` | `A-A1-A1` | 0.2 |

最后两行是用户新增明确的跨深度情况。若一方只有一级，则没有可比较的二级类别，应使用2.2节的深度差异表。

### 2.4 一级、二级正确，三级类别错误

双方都是三级且前两级一致、三级不同，记 **0.7分**。

例如预测 `A-A1-A12`、真值 `A-A1-A11`，得0.7分。

### 2.5 规则执行顺序

1. 校验标签格式与类别树路径。
2. 一级不同：0分。
3. 双方至少到二级且二级不同：0.2分。
4. 双方到三级且三级不同：0.7分。
5. 同深度、有效类别完全正确：1分。
6. 其余是正确分支上的跨深度预测，按2.2节计分。

非法格式或不存在的类别路径报错，不能通过截断或猜测名称强行计分。

## 3. 图像与数据集分类成绩

当前项目对预测框与真值框做旋转IoU匹配，阈值0.3，按预测置信度进行一对一匹配。匹配到的目标取得上述分类积分；漏检目标记0。

设图像i有G_i个真实目标，目标j获得积分r_ij，则：

`图像分类分 S_cls(i) = Σ_j r_ij / G_i`

`数据集分类分 = 所有图像分类分的算术平均`

单目标最高1分，因此除以目标数后已经归一化到[0,1]；乘100%得到百分制，不需要再做最大值归一化。当前分母是全部真实目标，包括漏检目标，并非只对检测成功的目标求平均。

当前代理实现的补充约定：无真实目标且无预测框的图像分类分记1；无真实目标但存在预测框记0；有真实目标图像的额外预测框通过检测分惩罚，不再次加入分类分母。上述匹配、空图和虚警处理为项目实现口径，仍需与官方评测程序核对。本文采用用户后续明确的逐目标层级积分口径，不将最早描述的分类P/R公式与之混算。

## 4. 与检测分和总分的关系

采用用户修正的 `N=TP+FN`、`M=TP+FP`，检测公式可化为：

`S_det(i) = 5TP / (5TP + FN + 4FP)`

无真值、无预测时检测分记1。检测分亦按图像平均。

`总分 = 0.5 × 检测分 + 0.5 × 分类分`

分类积分规则与旋转框几何评估分别计算。

## 5. 输出深度的期望积分决策

模型融合得到三级类别概率p_k。一级或二级概率是其全部后代三级概率之和。当前代理标签树有4个一级、21个二级、40个三级，共65个可输出标签。

真实标签标注深度D在推理时未知，使用可调参数：

`depth_prior = [P(D=1), P(D=2), P(D=3)]`

默认 `[0.1, 0.3, 0.6]`，即一级10%、二级30%、三级60%。这是当前代理协议的默认先验，不是模型的类别置信度，也不是已经确认的竞赛标注比例。

对每个候选输出a计算：

`U(a) = Σ_k p_k × Σ_d depth_prior[d-1] × reward(a, k, d)`

选择期望积分最大的输出。当前margin=0，数值同分优先选择较粗类别。若设置正margin，则在距最高期望积分不超过margin的标签中优先选粗类别。所有分类分支都已运行后才进行这一步，不构成计算早退。

对同一路径一级A、二级B、三级C，令a=P(A)、b=P(B)、c=P(C)，令q1/q2/q3为深度先验，则v3.2规则下：

- `U1 = (q1 + 0.6q2 + 0.4q3) a`
- `U2 = (0.8q1 + 0.2q2 + 0.2q3) a + (0.8q2 + 0.6q3) b`
- `U3 = (0.6q1 + 0.2q2 + 0.2q3) a + (0.6q2 + 0.5q3) b + 0.3q3 c`

默认先验对应：`U1=0.52a`、`U2=0.26a+0.60b`、`U3=0.24a+0.48b+0.18c`。实际在整棵类别树上比较全部候选，并非只比较预先选定的某一条路径。

**调整先验只影响模型选择输出标签，不修改单目标积分表，不改变真值深度，不重采样测试集，也不改变分类分母。** 模型概率可能失准，因此最大期望积分不保证每一幅图像或每一份有限测试集的实际积分最高。

## 6. 脚本参数与使用方法

统一参数为 `--depth-prior P1 P2 P3`。三个数均须有限、非负，且总和为1，允许某项为0。不接受 `[10,30,60]` 或总和不为1的输入，不做隐式归一化。

研究选型脚本省略参数时使用默认10%/30%/60%；确认和研究推理脚本优先继承选择记录中的先验，旧记录缺失时采用默认值。SARdetect省略参数时读取 `/workspace/SARdetect/B.models/v3_manifest.json` 中的 `classifier.depth_prior`。命令行覆盖只作用于本次运行，不会自动修改持久配置。

以下命令在远端已初始化Ascend运行环境中执行。

